# TFCB Homework 1

## Repository Overview

This repository has the results for homework 1 of TFCB.

## Description

This project trains a model that can predict the species of specimen from an image that comes from the most photographed specimens on AntWeb.

## Files

'main.py' - main code, where it all happens
'get Species_list.py' - Creates csv of the most photographed specimen on AntWeb
'get_dataset.py' - Functions for downloading and handeling the datasets.
'predict_image.py' - Load a model with trained weights and predict an image or a test set.

## Running

python main.py
